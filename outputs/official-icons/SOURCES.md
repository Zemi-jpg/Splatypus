# Workflow logo sources

Retrieved 20 September 2026. Logos retain their published appearance; they are scaled proportionally for the diagram.

- FFmpeg: official project mailing-list SVG attachment, https://ffmpeg.org/pipermail/ffmpeg-devel/attachments/20130806/480593ce/attachment.svg (announcement: https://ffmpeg.org/pipermail/ffmpeg-devel/2013-August/146910.html). Transparent outer margins trimmed for layout.
- COLMAP: https://raw.githubusercontent.com/colmap/colmap/main/src/colmap/ui/media/colmap-logo.svg
- Brush: https://raw.githubusercontent.com/ArthurBrussee/brush/main/apps/brush-app/assets/icon-256.png
- Rhino Gaussian Splatting: author's Food4Rhino listing https://www.food4rhino.com/en/app/rhino-gaussian-splatting ; original image https://www.food4rhino.com/sites/default/files/public/users-files/seghier/app/icon.png
- Krill: official Rhino package release https://yak.rhino3d.com/versions/krill/0.12.0 ; package https://files.mcneel.com/yak/packages/krill-0.12.0-rh8_32-win.yak . The 1024 × 1024 logo was extracted from the embedded PNG resource in Krill.rhp, whose resource names include Krill.Resources.Icons.Logo.Icon_LogoKrill_1024.png. No plugin code was executed or installed. The extracted image is krill-embedded-25.png. Homepage https://krill.verkare.com/ . The downloaded website favicon is the publisher's V mark and is NOT used in the workflow.
- Splatypus alignment and preview: existing project assets in Assets/Icons-Splatypus/svg; not represented as Grasshopper or Rhino brand logos.

Workflow references: local project code for JPG / COLMAP BIN / TXT / Brush PLY transfers and optional +90° X visualization copy; https://discourse.mcneel.com/t/rhino-gaussian-splatting/220672 for Rhino Gaussian Splatting PLY import; https://krill.verkare.com/ and https://discourse.mcneel.com/t/krill-3d-gaussian-splats-in-rhino-8-closed-beta/222338 for Krill PLY import and Gaussian rendering. Import routes are documented capabilities, not an end-to-end test of these external plugins.
